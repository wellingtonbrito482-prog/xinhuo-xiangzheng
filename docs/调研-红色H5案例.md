## 一、案例（按“可借鉴度”排序）

**1. 新华社《2021，送你一张船票》**｜2021-01-02｜第32届中国新闻奖融合报道一等奖
- 结构：横屏长卷，自动播放，用“红船”串起32个节点；开头先放几屏黑白灰画面铺陈背景，再进入彩色长卷。
- 视觉：用“金线”勾勒的国潮插画。文字是“小标题＋简要概述”，每屏只有二三十字。
- 交互：答对题“点亮一颗星”；让用户输入出生年份，长卷里会显示“距你出生还有 XX 年”；“暂停/回看”可调出事件导航，但只能回看已经看过的节点；最后生成带头像和编号的“船票”。
- 数据：全网浏览近5亿，H5 独立浏览1.13亿，平均阅读时长6分40秒。
- 来源：http://www.zgjx.cn/2021-11/23/c_1310327850.htm ；https://www.h5anli.com/cases/202102/100nian.html ；获奖目录 http://www.news.cn/politics/2022-11/08/c_1129112419.htm

**2. 人民日报《复兴大道100号》**｜2021-06（2021-06-30 发布）｜第32届中国新闻奖融合报道一等奖
- 结构：横屏手绘长卷，“一镜到底”，用一条路串起时间线，手机上约50屏，含300多个事件。
- 视觉：纪实手绘。墙上的标语和字体、人物服装都经过考据。
- 交互：滑屏浏览，点击场景弹出真实事件介绍和音频（用的是同期声、广播原声）；可做 AI 人脸融合，生成年代海报；湘江战役一屏有炸弹激起水花的动画。
- 数据：仅人民日报渠道浏览量超1.2亿，点赞超290万，微博话题阅读量近3.5亿，相关内容全网阅读量超10亿。
- 来源：http://www.zgjx.cn/2022-11/01/c_1310667990.htm ；https://www.thepaper.cn/newsDetail_forward_15457761

**3. 澎湃新闻《天渠：遵义老村支书黄大发36年引水修渠记》**｜2017-04-23｜中国新闻奖一等奖
- 结构：竖向下拉的长幅连环画，分7章，每章约2屏；以“水”为主线，读起来像水自上而下流淌。
- 视觉：朴素、带平面装饰感的黑白画风，人物写实，只用金色点缀。
- 声音：主人公清唱的地方歌谣、开渠炸石声、鸟鸣。
- 数据：系列报道发布约24小时后阅读量突破300万。
- 来源：https://www.cac.gov.cn/2019-05/21/c_1124523289.htm

**4. 中国网《最后，他说——英雄党员的生命留言》**｜2021-06-21｜第32届中国新闻奖融合报道二等奖
- 结构：6期，每期围绕一位英烈的“最后一句话”做成一个划屏长卷。

- 交互：轻击、长按、划动、拖拽；声音“小剧场”；动画用 GSAP 补间。
- 数据：全平台浏览超1000万，配套抖音作品播放115万。
- 来源：http://www.zgjx.cn/2022-11/01/c_1310667164.htm

**5. 封面新闻《走向胜利——毛泽东诗词里的长征》**｜2026-10-22（长征胜利90周年）

## 二、“柔和、不炫技”的手法，以及能否用纯静态网页低成本实现

| 手法 | 出处 | 静态实现方式 | 成本 |
|---|---|---|---|
| 单色画面＋一种点缀色（黑白配金或暗红） | 天渠、红色印记 | 插画统一做阈值处理，转成墨色一种颜色，红色只用在“火”上 | 低 |
| 木刻/版画质感 | 西安美院、求是网 | 叠一层纸纹或噪点 PNG（mix-blend-mode: multiply），或用 SVG feTurbulence 生成颗粒 | 低 |
| 先铺陈黑白，再进入彩色 | 船票 | 前2–3屏用 grayscale 滤镜，滚动到某个位置后过渡为彩色 | 低 |
| 少字：每节点只给小标题加二三十字 | 船票 | 纯排版 | 低 |
| 已读节点索引（只能回看看过的） | 船票 | IntersectionObserver 记录已读状态，侧栏只点亮已读节点 | 低 |
| 电报、摩斯码 | 上观、浙江广电 | 稿纸样式的 CSS，加逐字打出效果和点划字符 | 低 |
| 家书挖空、点开揭示 | 广州纪委 | details/summary 或点击切换 class | 低 |
| 旧报纸原版 | “红”报映长征 | 报头、竖排、分栏用 CSS writing-mode 实现，并注明史料出处 | 中 |
| 老照片“冲印”上色 | 红色冲印馆 | 用 filter: sepia 到 none 做 hover 或滚动过渡；真正的涂抹需要 canvas | 低到中 |
| 一镜到底长卷、手势、AI人脸融合 | 复兴大道、山河在握 | 需要大量手绘或 JS 识别 | 高，不建议 |

## 三、半天内可落地的 5 条改进

1. **把 AI 电报问答做成“电报稿纸”。** 回复框改成竖线稿纸，表头放“发报/收报/等级：加急/字数”。答案逐字打出，同时在表头旁用点划字符（· —）闪烁模拟发报声。整句打完后，盖一枚炬火红的“已译”小印章（SVG，旋转 −8°，multiply 混合，从 scale 1.3 缩到 1）。参考上观摩斯电码、浙江广电红色密电。约 1.5 小时。
2. **滚动地图加“已过”印章和已读索引。** 每经过一个湖南段节点（如通道、老山界），在节点上盖一个红章，顶部日期戳随滚动变化（1934.11 → 1934.12）。侧边小索引只点亮已经看过的站点，可以跳回，但不能跳到没看过的站点。参考船票的导航机制。约 1.5 小时。
3. **档案卡加“手写批注＋挖空字”。** 正文保持思源宋体；每张卡加一行手写体批注，只引入一款字体的子集。挑一个关键数字或地名挖空成下划线，点击后揭示答案和出处。参考广州《破译家书红色密码》。约 1 小时。
4. **统一版画质感，限定红色用量。** 全站叠一层纸纹或木刻颗粒（一张约 150KB 的 PNG，multiply 混合，不透明度 0.15–0.2）。插图统一阈值化为墨色一色。炬火红只用在火光、印章和关键行，面积控制在 5% 以内。首屏暮色前加 1–2 屏黑白灰铺陈，滚动后转入纸色。参考天渠、红色印记、西安美院、船票开头。约 1 小时。
5. **接力海报做成编号“路条/通行证”。** 用 Canvas 生成：顶部“湘征路条 No.000123”（本地递增或随机），中间一句用户接力语，加上“距 1934 年 X 月今 92 年”。骑缝处盖半枚红章，底部注明史料出处。参考船票编号、喜马拉雅的出生年份关联。约 1 小时。

**史实提醒：** 湘江战役的主战场在广西全州、兴安、灌阳。页面标题既然是“湖南段”，涉及湘江战役的节点要写清地理范围，避免被评委挑错。
